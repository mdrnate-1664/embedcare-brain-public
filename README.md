# The EmbedCare Brain

A public, interactive explainer of the EmbedCare Brain: what runs, when, what each piece leaves for the next, and how to build one yourself.

One self-contained HTML file and a one-page PDF summary. No external calls. Works offline and on a phone.

No client, person, price or id appears on this page. Roles stand in for names and every example is illustrative. The few counts shown are rounded down and refreshed daily, and this repository keeps only the latest version.
